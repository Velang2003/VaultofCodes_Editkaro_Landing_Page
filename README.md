# 🎬 EditKaro.in - Video Editing Portfolio Website  

This project is a modern, responsive portfolio website for a professional video editing service, **EditKaro.in**.  
It was developed as part of the **VaultofCodes - Assignment 4**.

## ✨ Features  

- 🎨 **Sleek, Dark UI** – A visually appealing, professional design with a dark theme.  
- 🎥 **Creative Portfolio** – Showcases commercials, documentaries, and social media ads.  
- 📱 **Responsive Design** – Adapts seamlessly across desktop, tablet, and mobile devices.  
- 📩 **Contact & About Sections** – Dedicated sections for client inquiries and service details.  
- 🧭 **Intuitive Navigation** – Clean and user-friendly interface.  

---

## 🛠️ Technologies Used  

- **HTML** – Website structure and content  
- **CSS** – Styling, layout, colors, and typography  
- **JavaScript** – Interactivity and dynamic behavior
